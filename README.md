# VPN-support bot for antizapret

Небольшой проект для управления [скриптами](https://github.com/GubernievS/AntiZapret-VPN) настройки VPN от [GubernievS](https://github.com/GubernievS) через телеграм бота

## Настройка

1. Переименовать app.example.yaml в app.yaml и заполнить его данными:
- bot_api_token: токен для доступа к вашему боту (получить можно у @BotFather в telegram)
