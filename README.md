<h1 align="center" >VPN Support Bot for antizapret</h1>

Небольшой проект для управления [скриптами](https://github.com/GubernievS/AntiZapret-VPN) настройки VPN от [GubernievS](https://github.com/GubernievS) при помощи телеграм бота в удобном интерфейсе

## Настройка

### 1. Переименовать app.example.yaml в app.yaml и заполнить его данными:
- bot_api_token: токен для доступа к вашему боту (получить можно у @BotFather в telegram)
- admin_ids: telegramID пользователей для доступа к боту
